# Morax Code (iOS)

Native SwiftUI client for Emdash's Mobile access gateway (fork-only). Setup, security model and
limits: [docs/fork/mobile-remote/README.md](../../docs/fork/mobile-remote/README.md).

- iOS 26, Swift 6 strict concurrency, Observation.
- `Packages/MoraxWire`: `MoraxWire` (Wire client: frames, calls, live states with Immer
  patches, live logs, event streams, live jobs) and `MoraxCodeKit` (gateway access, pairing,
  models, task board, status rules, new-task input). No UI; `swift test` runs in seconds.
- `MoraxCode/`: the app (SwiftUI). Terminal: [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm)
  (MIT, pinned to 1.18.0: newer releases add a build-tool plugin Xcode must approve). Design:
  [MoraxDesign](https://github.com/Etienne-Morax/morax-design).
- `Fixtures/`: recorded from the TypeScript side, replayed by the Swift tests.
  - `wire-protocol.json`: a scripted Wire session with exact frames
    (`packages/wire/src/api/transports/ios-fixtures.test.ts`).
  - `mobile-contract.json`: endpoint paths and live topic ids
    (`apps/emdash-desktop/src/core/features/mobile-remote/node/mobile-contract-fixture.test.ts`).
  - `status-logic.json`: the desktop's agent-status rules on every small case (same test).

  Regenerate after a protocol or contract change: run those tests with `UPDATE_WIRE_FIXTURES=1`.

## Build and test

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
`project.yml` and never committed.

```bash
cd apps/morax-code-ios && xcodegen generate
```

```bash
cd apps/morax-code-ios/Packages/MoraxWire && swift test
```

```bash
cd apps/morax-code-ios && xcodebuild -project MoraxCode.xcodeproj -scheme MoraxCode -destination 'platform=iOS Simulator,name=iPhone 18 Pro' test
```

SwiftTerm compiles a Metal shader: on a fresh Xcode, run `xcodebuild -downloadComponent MetalToolchain` once.

`MoraxCodeUITests` drives the app against a live, already paired dev desktop and creates a real
task; it is skipped unless `MORAX_LIVE_DESKTOP=1` is set. Debug builds accept a
`-MoraxOpenURL <moraxcode://…>` launch argument (pairing link, `moraxcode://task/<project>/<task>`,
`moraxcode://new`) for scripted screenshots.

## Install on an iPhone

Open `MoraxCode.xcodeproj`, select your iPhone, Run. Signing is automatic with the personal team
(`DEVELOPMENT_TEAM` in `project.yml`). Nothing is uploaded to TestFlight or the App Store.

(paid developer account) and a sender on the Mac; the desktop's Web Push service (VAPID, from the
former web app) could be replaced by an APNs sender. Not done; ask before adding any external push
service.
